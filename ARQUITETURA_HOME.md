## 📱 ESTRUTURA DE PÁGINAS (Completa)

### PÚBLICAS (Sem login)
```
/                           → HOME (essa arquitetura)
/scrims                     → Lista de scrims abertos (filtros, inscrição)
/ranking                    → Ranking nacional (times, jogadores, trending)
/campeonatos                → Lista histórico de torneios (calendar, resultados)
/agentes-livres             → Marketplace de jogadores (filtros, profiles)
/perfil/[username]          → Perfil público do jogador (stats, carreira, badges)
/academy                    → Sistema Academy (Sub-14, Sub-17, Sub-20)
/sobre                      → Sobre The Zero Base (missão, valores)
/regras                     → Regulamento oficial
/ajuda                      → FAQ, suporte
```

### AUTENTICADAS (Com login)
```
/auth                       → Login/Registro (Google, Discord, Twitch)
/dashboard                  → Painel do jogador (stats, histórico, inscrições)
/dashboard/time             → Gerenciar time (membros, escalas, histórico)
/dashboard/inscricoes       → Torneios inscritos (status, resultados)
/overlay                    → Gerador overlay (customização, preview)
/admin (só admins)          → Painel administrativo
  ├─ /admin/torneios        → Criar/editar torneios
  ├─ /admin/resultados      → Registrar resultados
  ├─ /admin/users           → Gerenciar usuários
  ├─ /admin/cms             → Editar home, seções, textos
  └─ /admin/patrocinios     → Ativar/gerenciar patrocínios
```

## 🎯 ESTRATÉGIA DE NAVEGAÇÃO (UX)

### Fluxo Novo Usuário
```
1. Acessa HOME
2. Lê hero + diferenciais (2 min)
3. Vê 3 categorias (escolhe a sua)
4. Clica em [COMPETIR AGORA] ou [SABER MAIS]
5. Vai pra /auth
6. Cria conta (2 min)
7. Completa onboarding (nome, foto, Discord)
8. Vai pra /dashboard
9. Cria ou entra em time
10. Inscreve em torneio
```

### Fluxo Retorno (Já Cadastrado)
```
1. Acessa site
2. Header reconhece login
3. Menu muda: [MEU DASHBOARD]
4. Opções rápidas:
   ├─ Ver meus torneios
   ├─ Ver meu ranking
   ├─ Inscrever novo torneio
   └─ Ver notificações
```

## 🎨 DESIGN SYSTEM

### Paleta
```
Primary:   #1a1a2e (Deep dark blue)
Secondary: #e8b24a (Gold/amber — prêmios, destaque)
Accent:    #ff3b3b (Red — urgência, CTAs)
Neutral:   #ffffff (Texto)
Muted:     #999999 (Subtítulos)
```

### Tipografia
```
Headlines:  Barlow Condensed Bold (títulos impactantes)
Body:       Inter Regular (leitura)
Numbers:    JetBrains Mono (stats, rankings)
```

### Componentes
```
Botões:     Rounded 8px, gradient hover, shadow
Cards:      Rounded 12px, hover lift, border subtle
Inputs:     Rounded 6px, focus outline gold
Tables:     Striped alternate, hover highlight
Modals:     Dark overlay, animation slide-up
```

### Motion
```
Fade-in:     200ms ease-out (seções ao scroll)
Hover:       150ms ease-out (interação)
Loading:     Spinner customizado (The Zero Base colors)
Success:     Green pulse + checkmark
```
